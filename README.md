# Global Population Distribution & Demographic EDA

## Overview
Performed Exploratory Data Analysis (EDA) on the World Bank Total Population dataset to visualize demographic distributions and growth trends across countries and age groups.

## Tech Stack
- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn

## Key Insights
- Built bar charts and histograms to analyze population skewness, top-populated nations, and year-over-year growth patterns.
